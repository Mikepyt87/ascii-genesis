# Raspberry Pi 4 and Waveshare 7.9-inch build

For the supplied enclosure build, **print one case and two legs** using the [models and print guide](../3d-printing/README.md). A 3D printer or printing service is needed. Import STLs in millimeters at 100% scale; the leg file needs two printed copies.

Follow the [complete setup instructions](SETUP.md) for the full hardware list, printing and assembly, GitHub installation, Raspberry Pi desktop icons, automatic updates, optional boot startup, and troubleshooting. You can test the software before enclosing the hardware.

To exit with the touchscreen, tap the water and select **Close ocean**. The desktop launcher closes its dedicated Chromium session and local server, then releases the app lock. Reopen it using the desktop icon. The button does not shut down the Raspberry Pi or close your other browser sessions.

This ocean builds on [Asciiquarium](https://github.com/cmatsuoka/asciiquarium) by Kirk Baucom, with most art credited upstream to Joan Stark and expanded marine biodiversity by Claudio Matsuoka. [OpenGhost](https://github.com/xanderchinxyz/OpenGhost) inspired the initial display exploration. Please see [Credits and project origins](../CREDITS.md) and give those projects a look too.
