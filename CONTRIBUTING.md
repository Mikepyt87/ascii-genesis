# Contributing to ASCII Genesis

This project builds on the work of the [Asciiquarium creators and OpenGhost community](CREDITS.md). Preserve that history when adding your own work.

## Credit and source tracking

- Keep original authors' copyright and license notices intact, including the preserved upstream source.
- For adapted artwork or code, record its original project, author when identified, source link, license, and your changes in THIRD-PARTY.txt and CREDITS.md.
- Add your name or handle for your own contributions. Do not label adapted work as an original drawing.
- Keep source drawings, the Ocean Library, screenshots, and build instructions current with working features.
- Keep the project's GPL-2.0-or-later requirements when contributing code or artwork; bring license questions to the maintainer before adding external assets.

## Verify a change

Run the checks listed in [the setup guide](raspberry-pi/SETUP.md#performance-and-validation). Simulation changes should preserve the calm pace, off-screen arrivals and departures, visible contact for catches, and bounded populations. For enclosure changes, document dimensions, print quantity, scale, and any verified assembly instructions. Keep untested print settings clearly identified.
