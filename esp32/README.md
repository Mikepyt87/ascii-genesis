# ESP32 editions

The miniature **[Waveshare ESP32-S3-Touch-LCD-1.47 edition](1.47-inch/README.md)** is being developed separately from the [Raspberry Pi ocean](../README.md).

It includes a browser simulation for visual review and prototype firmware with phone Wi-Fi setup and wireless updates. It still needs physical board testing before a stable release. The Pi installation, updates, enclosure, and 1280 × 400 renderer remain unchanged.
