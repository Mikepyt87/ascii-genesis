# ESP32 editions

The miniature **[Waveshare ESP32-S3-Touch-LCD-1.47 edition](1.47-inch/README.md)** is being developed separately from the [Raspberry Pi ocean](../README.md).

Its current deliverable is a local browser simulation for visual review. It is not ready to flash to a board. The Pi installation, updates, enclosure, and 1280 × 400 renderer remain unchanged.
